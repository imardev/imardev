## 👋 About Me

Hi! I'm a developer who enjoys building practical software and learning new technologies through real-world projects. I believe the best way to improve is by creating things, solving problems, and refining them over time.

My current focus is frontend development with React, while steadily expanding into backend development and cross-platform applications. My goal is to become a full-stack developer capable of designing complete, reliable, and user-friendly software.

## 🌱 What I'm Working On

* Creating modern web applications with **React**.
* Learning backend development with **Node.js**, **Express**, and databases.
* Exploring cross-platform development for desktop and mobile.
* Continuously improving software architecture and development practices.
