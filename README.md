## 👋 Sobre mí

Soy desarrollador web y estudiante de **Desarrollo de Aplicaciones Web (DAW)**.

Actualmente estoy centrado en el desarrollo **Front-end con React**, mientras amplío mis conocimientos en desarrollo Back-end, bases de datos y desarrollo de software.

Como parte de mi formación, también estoy aprendiendo **Java**, además de seguir trabajando con **JavaScript y Python** para desarrollar diferentes tipos de proyectos.

Me interesa entender cómo funcionan las aplicaciones de principio a fin: desde la interfaz y la experiencia de usuario hasta la lógica del servidor, los datos y la infraestructura.

Mi objetivo es seguir creciendo como desarrollador y evolucionar hacia un perfil **Full Stack**, creando software útil, mantenible y con una buena experiencia de usuario.

## 🚀 En qué estoy trabajando

- ⚛️ Desarrollo de aplicaciones web modernas con **React**.
- 🟢 Desarrollo Back-end con **Node.js** y **Express**.
- ☕ Aprendizaje y desarrollo de aplicaciones con **Java**.
- 🐍 Desarrollo de proyectos con **Python**.
- 🗄️ Aprendizaje de bases de datos y arquitectura de aplicaciones.
- 🖥️ Exploración del desarrollo de aplicaciones multiplataforma.
- 🧩 Mejora continua de arquitectura, organización y buenas prácticas.
