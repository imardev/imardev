## 👋 Sobre mí

Soy desarrollador web y estudiante de **Desarrollo de Aplicaciones Web (DAW)**.

Trabajo en todo el ciclo de una aplicación: interfaces con **React**, APIs con **Node.js y Express**, bases de datos con **PostgreSQL y Prisma**, y el despliegue en mi propio servidor.

Me interesa entender cómo funcionan las aplicaciones de principio a fin: desde la interfaz y la experiencia de usuario hasta la lógica del servidor, los datos y la infraestructura.

Mi objetivo es seguir creciendo como desarrollador **Full Stack**, creando software útil, mantenible y con una buena experiencia de usuario.
